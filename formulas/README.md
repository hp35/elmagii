# Collection of formulas in classical electromagnetic theory

This repository contains the source for a collection of formulas, compiled
specifically for the course on Electromagnetic Theory II (1TE626) for
Engineering Physics (master level) at Uppsala University.
This set of formulas is convenient to have at hand when solving problems.

## Primary files of interest

[formulas-twocol.tex](formulas-twocol.tex) - Plain TeX source code for the
  compact two-column version of the collection of formulas.

[formulas-twocol.pdf](formulas-twocol.pdf) - Compiled document containing
  the compact two-column version of the collection of formulas.

## Contributing

Reports on errors, inconsistencies or improvements in general are most welcome!

## Compiling the TeX code and figures

In the present directory, the included `Makefile` can be used to regenerate the
entire collection of formulas. Just run `make` and ensure to install any
missing components in case there are any complaints.
